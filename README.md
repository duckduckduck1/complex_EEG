# Лаборатория «Умного сна» — приложение оператора

Windows-приложение на Flutter для нейробиологической лаборатории, которая
исследует сон на мышах с помощью собственного ЭЭГ-устройства. Приложение
принимает сигнал по BLE, показывает графики, ведёт запись эксперимента с ручной
разметкой и управляет фотобиомодуляцией (ФБМ).

Результат работы оператора — пакет эксперимента на диске: `signal.bin`,
`experiment.json`, `journal.ndjson`.

Подробнее — в [продуктовом видении](docs/vision.md).

## Структура репозитория

| Путь | Что это |
|------|---------|
| `lib/` | код приложения: фичи, слои `presentation → application → domain`, `data → domain` |
| `test/` | тесты на фейках, без железа |
| `third_party/` | вендорный форк `flutter_blue_plus_winrt` — быстрый поиск устройств в Windows |
| `windows/` | платформенная обвязка целевой платформы |
| `android/`, `ios/`, `linux/`, `macos/`, `web/` | остатки шаблона Flutter, не поддерживаются |
| `docs/` | документация: видение, решения, контракты, дизайн по компонентам |

## Быстрый старт

Нужен Flutter stable (текущая версия — 3.41.4, её же пинует CI).

```bash
flutter pub get
flutter run -d windows
```
