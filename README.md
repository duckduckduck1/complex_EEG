# Лаборатория «Умного сна»

Платформа данных нейробиологической лаборатории, которая исследует сон на мышах
с помощью собственного ЭЭГ-устройства. Проект состоит из двух частей:

- **Сервер + веб-кабинет** — сотрудники загружают, просматривают и скачивают
  эксперименты; хранение в MinIO (слой `bronze`) и PostgreSQL (метаданные).
- **Flutter-приложение оператора** (в работе) — приём сигнала с устройства по
  BLE, графики, структурированная разметка, фотобиомодуляция (ФБМ).

Подробнее — в [продуктовом видении](docs/vision.md).

## Структура репозитория

| Путь | Что это |
|------|---------|
| `server/` | FastAPI backend: upload flow, веб-API, аутентификация |
| `scripts/db_scripts/` | SQL init — источник истины схемы БД |
| `scripts/minio/` | инициализация бакетов MinIO |
| `infra/` | docker, nginx, ansible, мониторинг, бэкапы |
| `docs/` | документация (видение, решения, дизайн) |
| `docker-compose.yml` | локальный и стендовый запуск всего стека |

## Быстрый старт (локально)

Нужен Docker. Скопируй пример окружения и подними стек:

```bash
cp .env.example .env   # при необходимости поправь секреты
docker compose up -d
```

Порты по умолчанию: API — `8000`, веб — `8080`, консоль MinIO — `9001`,
Grafana — `3000`, Prometheus — `9090`.

## Тесты сервера

Запускаются из каталога `server/` (там `pyproject.toml` с настройками pytest):

```bash
cd server
python -m pytest
```

> Запуск из корня репозитория не сработает: `pythonpath` и `testpaths` заданы
> относительно `server/pyproject.toml`.
