# ADR 0001: Репозиторий посвящён только приложению оператора

## Статус

Принято (2026-07-17). Заменяет прежний ADR 0001 «EEG-only MVP scope» и
ADR 0002 «MinIO bronze storage» — оба описывали серверную часть и вместе с ней
переехали в репозиторий веб-лаборатории.

## Контекст

Репозиторий `complex_EEG` начинался как платформа данных лаборатории: FastAPI
backend, PostgreSQL, MinIO, веб-кабинет, инфраструктура (docker, nginx, ansible,
мониторинг, бэкапы) и Flutter-приложение оператора в одной кодовой базе.

По ходу работы веб-лаборатория выделилась в самостоятельный проект и развивается
в **отдельном репозитории**. Здесь же вся активная разработка идёт только по
приложению оператора. Совмещение двух продуктов в одном репозитории давало:

- CI, который проверял инфраструктуру и **вообще не гонял тесты приложения**;
- правила и документацию, наполовину описывающие несуществующий здесь backend;
- размытую границу ответственности и лишний шум в ревью.

## Решение

Репозиторий содержит **только приложение оператора** (Flutter, целевая платформа
Windows). Приложение живёт в корне репозитория.

Удалено: `server/`, `infra/`, `scripts/`, `docker-compose.yml`, `.env.example`,
документация сервера и инфраструктуры, HTTP API, диаграммы комплекса, доки
синхронизации с сервером. Всё это доступно в истории git и в репозитории
веб-лаборатории.

CI проверяет приложение: формат, `flutter analyze`, `flutter test` и отсутствие
хвостовых пробелов.

## Граница с веб-лабораторией

Точка стыка одна — **формат пакета эксперимента**
([reference/experiment_package.md](../reference/experiment_package.md)):
приложение пишет пакет на диск оператора, веб-лаборатория принимает его при
загрузке. Формат описан здесь, потому что его порождает приложение; исполняемый
валидатор живёт на стороне лаборатории.

Изменения формата — согласованные: правка дока в этом репозитории и валидатора
в репозитории лаборатории идут вместе.

## Вне области

- Выгрузка пакета на сервер из приложения. Когда дойдём — заведём отдельный ADR;
  контракт будет диктовать сторона лаборатории.
- Обработка и анализ сигнала за пределами того, что нужно оператору у стенда.
- Микроскопия и другие домены данных.

## Последствия

- Правила работы (`CONTRIBUTING.md`, `CLAUDE.md`), README и карта документации
  описывают только приложение.
- Пакет эксперимента перестаёт иметь «серверный источник истины»: контракт
  фиксирует документ, а не код в этом репозитории.
- Возврат серверной части сюда потребует нового ADR.
