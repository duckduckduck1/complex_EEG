# Визуализация и обработка сигнала

Графики оператора и DSP под ними: что рисуем, откуда берём данные и как считаем
спектр и ритмы. Документ описывает текущее состояние кода.

## Что видит оператор

Три графика на вкладке устройства, каждый можно скрыть в панели настроек:

| График | Что показывает |
|--------|----------------|
| Сигнал | живой сигнал во времени, сырой и/или отфильтрованный |
| Спектр | амплитудный спектр в dB по частоте |
| Ритмы | мощность полос Delta, Theta, Alpha, Beta во времени |

Все данные живые, из памяти — графики **не читают `signal.bin`**. Графика
сохранённого эксперимента в приложении нет.

## Поток данных

```text
BLE-пакеты → DeviceEegBridge → RtEegDataBloc → графики
```

`RtEegDataBloc` держит кольцевой буфер на `bufferSize = 1024` отсчёта при
частоте 250 Гц: при переполнении старые отсчёты отбрасываются. Он же считает
спектр и мощность полос и отдаёт всё готовым состоянием — виджеты только рисуют.

Событие `RtEegResetRequested` обнуляет буферы: его шлёт вкладка при старте
записи, чтобы эксперимент начинался с чистых графиков.

## Обработка сигнала

`SignalProcessor(bufferSize, sampleRate, settings)` — вся математика:

- **Фильтры отображения** (`filterSignal`) — Butterworth: LP, HP и Notch,
  параметры берутся из панели настроек. Фильтр применяется ко всему буферу
  целиком, поэтому годится только для картинки. Запись использует **другой**,
  потоковый фильтр (см. [recording.md](recording.md)).
- **Спектр** (`computeFrequencySpectrum`) — окно Ханна, затем FFT; размер входа
  обязан совпадать с `bufferSize`, а `bufferSize` — быть степенью двойки.
  Результат — амплитудный спектр в dB.
- **Мощность полос** (`computeBandPowers`) — интегрирует спектр по полосам,
  переводя dB в линейную шкалу, и нормирует на общую мощность 0.5–35 Гц:

  | Полоса | Диапазон, Гц |
  |--------|--------------|
  | Delta | 0.5 – 4.0 |
  | Theta | 4.0 – 8.0 |
  | Alpha | 8.0 – 13.0 |
  | Beta | 13.0 – 35.0 |

  Точка на графике ритмов добавляется раз в секунду (каждые `sampleRate`
  отсчётов), а не на каждый отсчёт.

## Правила отрисовки

Построено на `fl_chart`:

- анимация выключена (`duration: Duration.zero`) — иначе живой график дёргается;
- данные обрезаются по области построения (`clipData`);
- подсказки не вылезают за границы графика (`fitInsideVertically`,
  `fitInsideHorizontally`), по осям оставлен запас;
- масштаб колесиком мыши через `FlTransformationConfig`; отдельная кнопка
  сбрасывает масштаб в исходный.

Тема — общая тёмная «Осциллограф» из `lib/theme.dart`; цвета берутся из неё, а не
хардкодятся в виджетах.
