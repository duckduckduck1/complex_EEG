# Эксперименты (локальный список)

Документ описывает работу со списком сохранённых экспериментов, открытие
эксперимента, локальные действия и подготовку пакета для загрузки через Web UI.

---

## BLoC

```text
ExperimentIndexBloc
ExperimentListFilterCubit
ExperimentViewerBloc
ExperimentActionsBloc
PackageExportBloc
ExperimentPackageValidationCubit
```

Список, фильтры, выбранный эксперимент и действия с локальными файлами
управляются через BLoC/Cubit.

---

## Список экспериментов

Экран сохранённых экспериментов показывает:

```text
display_name
experiment_id
created_at
duration
sample_count
recording_status
package_status
last_error
folder_path user-visible optional
```

`folder_path` можно показывать пользователю как справочную информацию, но
внутренние операции не должны строиться на произвольном вводе пути.

---

## Фильтры и поиск

Фильтры:

```text
recording_status
package_status
date_from
date_to
поиск по тексту в display_name и experiment_id
```

Сортировка:

```text
created_at_desc
created_at_asc
display_name_asc
package_status_asc
```

---

## Открытие эксперимента

При открытии сохранённого эксперимента:

1. приложение читает локальный индекс;
2. проверяет наличие папки;
3. проверяет `signal.bin`;
4. читает `experiment.json`;
5. создаёт `ExperimentViewerBloc`;
6. создаёт scoped `AnnotationBloc` и `VisualizationBloc`.

Подключение по BLE не нужно для просмотра сохранённого эксперимента.

---

## Экспорт пакета

Экспорт пакета означает, что папка или `.zip`-архив содержит:

```text
signal.bin
experiment.json
journal.ndjson optional
app.log optional
```

Перед выдачей пакета `ExperimentPackageValidationCubit` проверяет его по
[формату пакета эксперимента](../reference/experiment_package.md).
`PackageExportBloc` отвечает за создание опционального `.zip`-архива или показ
пользователю готовой папки.

По сети приложение пакет не отправляет: оператор забирает папку с диска.

---

## Локальное удаление/архивирование

Удаление локальной папки:

- только вручную;
- только после подтверждения пользователя.

Архивирование может переместить папку в выбранное пользователем место, но должно
обновить локальный индекс.

---

## Пересборка индекса

Если локальный индекс повреждён, приложение может пересканировать
`experiments_root`.

Пересборка использует:

- `experiment.json`;
- размер `signal.bin`;
- `journal.ndjson`, если финальный JSON отсутствует;
- метаданные папки.

---

## Проверки реализации

- список строится из состояния BLoC;
- удаление требует подтверждения и выполняется только вручную;
- открытие сохранённого эксперимента работает офлайн;
- пересборка индекса восстанавливает записи экспериментов;
- проверка пакета не требует сети;
- экспорт не изменяет `signal.bin`.
